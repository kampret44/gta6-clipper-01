A vertical YouTube Short cut from Rockstar's Grand Theft Auto VI Trailer 2 — the most-watched GTA VI footage of launch week — with a make.fun pitch end-card: make clips like this with AI, and earn money doing it. The program in this repo carries the video's YouTube address: given VIDEO.json, main.ts writes it to the output directory, which is how make.fun finds the entry's video.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
